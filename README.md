# Floating CSS Editor for SillyTavern

A draggable, CSS editor for SillyTavern that floats above your chat interface.

## Features

- **Floating Window**: Draggable editor that stays on top
- **Auto-Sync**: Automatically loads CSS when you switch themes
- **Live Metrics**: Shows line count and file size in KB
- **Collapsible**: Minimize to header or hide completely
- **FAB Button**: Quick access button when editor is hidden
- **Smooth Animations**: Polished UI with subtle transitions

## Installation

1. Open SillyTavern
2. Go to **Extensions** > **Install Extension**
3. Paste this repository URL or download and extract to `public/scripts/extensions/`
4. Refresh SillyTavern

## Usage

- **Drag**: Click and drag the header to reposition
- **Refresh (🔄)**: Load current theme's CSS
- **Collapse (_)**: Minimize to just the header
- **Close (×)**: Hide editor (shows FAB button in bottom-right)
- **Apply**: Force apply CSS changes
- **Clear**: Remove all CSS

## Settings

In Extensions panel:
- **Show floating CSS editor**: Toggle extension on/off
- **Auto-load CSS when theme changes**: Automatically sync with theme changes
